# HRI-class-materials
Class demonstration materials for Human Robot Interaction (Fall 2026)

## Contents

| Folder | What it is |
|---|---|
| `intro_claude_code/` | Intro demos for working with Claude Code |
| `modality_experiment/` | Flask demos of three modalities: live video, speech-to-text (Whisper) and text-to-speech (Piper) |
| `modality_experiment_part2/` | Video annotation, object detection (YOLOv8), hand tracking and voice-controlled drawing (MediaPipe, Whisper). Self-contained, so it can be shared on its own |
| `old_materials/` | Earlier class projects (MCP/YOLO, TOON demos) |

Each folder has its own README with setup and run instructions.
